About

I'm Suvojit, an Android developer interested in what happens when AI stops being a remote API call and starts running next to the user. Most of my work is about that boundary: agent loops, local inference, permissions and the plumbing that makes them safe enough to use.

I work in Java and Kotlin, write C++ when the JVM gets in the way, and try to keep things reproducible.

  • Java, Kotlin
  • Android SDK, Jetpack Compose
  • NDK, CMake, llama.cpp
  • SQLite, WebView, Shizuku, Termux
  • GitHub Actions
